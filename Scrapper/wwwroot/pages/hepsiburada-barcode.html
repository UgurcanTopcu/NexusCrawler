Process & Upload Images

Excel should have barcodes in the first column (A). Header row is optional.

ℹ️ How it works

  • Upload an Excel file with barcodes (EAN/UPC/GTIN) in column A
  • Each barcode is searched on Hepsiburada via ScrapeDo API
  • Results show if product exists and include the product URL
  • Download the results as an Excel file
